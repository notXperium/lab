# Datenblock

## Was ist das?
Um meine Python-Skills und vor allem mein Verständnis für Datenverarbeitung aufzufrischen, habe ich 5 kleine Aufgaben umgesetzt. Die Daten sind dabei immer kleine Habit-Einträge, wie in meinem eigenen Tracker.

## Inhalt
| Name | Was? |
| --- | --- |
| [Datenblock 1](/datenblock/d1.py) | Zählende Schleifen mit `enumerate` und `range` |
| [Datenblock 2](/datenblock/d2.py) | Dictionaries als Zähler, das Häufigste finden |
| [Datenblock 3](/datenblock/d3.py) | Verschachtelte Daten gruppieren |
| [Datenblock 4](/datenblock/d4.py) | Daten aus einer `.jsonl`-Datei einlesen, Durchschnitt pro Tag |
| [Datenblock 5](/datenblock/d5.py) | Mit `datetime` Einträge der letzten 7 Tage filtern |
